# Records

- Record types are a way to define a new data type in C#.
- here is tabular difference between record type and class type.

| Record Type | Class Type |
|-------------|------------|
| Record types are reference types. | Class types are reference types. |
| Record types are immutable by default. | Class types are mutable by default. |
| Record types are used to create immutable data types. | Class types are used to create mutable data types. |
| Record types are used to create data types that are used for storing data. | Class types are used to create data types that are used for storing data. |
